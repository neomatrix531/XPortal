# XPortal

XPortal - Full Cloud Linux Desktop on Android with no Payment.
It also uses an Appwrite bucket for data.
Each user's progress is stored with a save code.
Load and Save files.
OpenGL Support.
Wayland App Support.

# Security

Each save code is encrypted with maximum security, then stored on my Appwrite Bucket.
Added my secure web browser to it.
Sandboxed web browsers are emulated in a webpage in the secure browser.

# Explaining what the secure web browser does

It runs a secure network with no real access to the internet.
But there is a webpage in the secure network which lets you emulate any browser of your choice.

# Docker Containers

Each Docker app on each user's desktop is always on and running on my server.
It always saves.
